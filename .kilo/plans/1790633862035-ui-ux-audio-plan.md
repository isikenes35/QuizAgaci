# Quiz Platform: UI/UX & Audio Implementation Plan

## Goal
Implement a premium, game-like experience strictly focused on Mobile-First design. Ensure snappy animations using `framer-motion` and add satisfying sound effects using the Web Audio API without the need for external asset files.

## 1. Frame & Physics (Animation Style)
- **Style**: Fast & Snappy competitive feel.
- **Framer Motion Constants**:
  - Snappy Spring: `transition={{ type: "spring", stiffness: 400, damping: 25 }}`
  - Pop-in: `initial={{ scale: 0.9, opacity: 0 }} animate={{ scale: 1, opacity: 1 }}`

## 2. Audio Strategy (Web Audio API)
Implement a zero-dependency utility using `AudioContext` for sound synthesis.
- **Creates**: `frontend/src/utils/audioSystem.ts`
- **Tones Needed**:
  - `playPop()`: Short fast beep for button taps / answer selections.
  - `playCorrect()`: Ascending chime sequence for correct answer screen.
  - `playWrong()`: Low descendant buzz for wrong answer screen.
  - `playStart()`: High-energy swoosh/chord for question start.
  - `playTick()`: Metronome-like soft click for low time left (< 5s).
- **Integration**:
  - Execute these lightweight functions directly inside event listeners `onClick` and SignalR Hub events.

## 3. UI Layer Enhancements (Mobile-First)

### A. HomePage (`HomePage.tsx`)
- Wrap the main "Join a Game" card in `<motion.div>` with a slide-up fade (`y: 20 -> 0`).
- Use `<motion.button>` for the "Enter" button with `whileTap={{ scale: 0.95 }}`.
- Trigger `playPop()` on button click.

### B. Game Lobby (`GameLobbyPage.tsx`)
- Display a bouncy "You're in!" badge.
- Enhance the `animate-pulse` waiting dots utilizing `framer-motion` stagger children for smoother loop.

### C. Player Game Screen - Critical Mobile View (`PlayerGamePage.tsx`)
- **Timer element**: Use a floating sticky top bar for the timer, smooth transitions for numbers.
- **Options Grid**: 
  - Wrap buttons in `<motion.button>` with stagger animations so they pop in one-by-one.
  - Add robust `whileTap={{ scale: 0.95, backgroundColor: "#e5e7eb" }}` interactions.
- **Results Screen**:
  - Correct/Wrong banner MUST explode in. Use `<motion.h2 initial={{ scale: 0 }} animate={{ scale: 1, rotate: [-5, 5, 0] }} />` for "Doğru!".
  - Call `playCorrect()` or `playWrong()` based on the outcome rendered.

### D. Host Game Screen (`HostGamePage.tsx`)
- **Leaderboard**: Add container stagger `variants` to table rows.
  - Make the 1st place Row noticeably larger and give it a drop shadow.
- **Question Layout**: Slide-in title text, fade-in image.
- **Sound**: Play `playStart()` on `gameHubService.onQuestionStarted`.
